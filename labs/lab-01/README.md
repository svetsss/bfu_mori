## Запуск

Из этой папки установите зависимости и откройте ноутбук:

```sh
python -m pip install -r requirements.txt
jupyter lab work.ipynb
```

Запускайте ячейки сверху вниз, рабочая папка — `labs/lab-01/`.

## Проверка

```sh
python test_work.py
```

Тест загружает определения из `work.ipynb` и проверяет поведение функций или модели. Полное обучение и загрузка датасетов для теста не нужны.

В `variants/` сохранены отличающиеся предыдущие версии, в `scripts/` — исходный Python-код. Основная работа — `work.ipynb`.
