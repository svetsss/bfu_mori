## Запуск

Из этой папки установите зависимости и откройте ноутбук:

```sh
python -m pip install -r requirements.txt
jupyter lab work.ipynb
```

Запускайте ячейки сверху вниз, рабочая папка — `labs/lab-08/`.

## Проверка

```sh
python test_work.py
```

Тест загружает определения из `work.ipynb` и проверяет поведение функций или модели. Полное обучение и загрузка датасетов для теста не нужны.

MNIST: 55 000 train / 5 000 validation / 10 000 test. Тестовая accuracy выполненного запуска — 98,09%. Данные загружаются в `../../.lab-data/`.
