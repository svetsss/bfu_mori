## Запуск

Из этой папки установите зависимости и откройте ноутбук:

```sh
python -m pip install -r requirements.txt
jupyter lab work.ipynb
```

Запускайте ячейки сверху вниз, рабочая папка — `labs/lab-10/`.

## Проверка

```sh
python test_work.py
```

Тест загружает определения из `work.ipynb` и проверяет поведение функций или модели. Полное обучение и загрузка датасетов для теста не нужны.

Использовано 1 000 train / 300 validation / 300 test из Cats vs Dogs. Backbone заморожен, голова обучается 30 эпох. Проверено восемь вариантов; повышение точности baseline не найдено. Baseline: validation 97,67%, test 98,00%. Разбиение — `split_10.json`, метрики — `metrics_10.json`. Полные данные и веса загружаются при первом запуске в `../../.lab-data/`.
