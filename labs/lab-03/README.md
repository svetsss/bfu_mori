## Запуск

Из этой папки установите зависимости и откройте ноутбук:

```sh
python -m pip install -r requirements.txt
jupyter lab work.ipynb
```

Запускайте ячейки сверху вниз, рабочая папка — `labs/lab-03/`.

## Проверка

```sh
python test_work.py
```

Тест загружает определения из `work.ipynb` и проверяет поведение функций или модели. Полное обучение и загрузка датасетов для теста не нужны.

Условие состоит из трёх частей: `condition.ipynb`, `condition_2.ipynb`, `condition_3.ipynb`. Данные «Яблоки и груши» находятся в `apples_pears.csv`.
