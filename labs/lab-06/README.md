## Запуск

Из этой папки установите зависимости и откройте ноутбук:

```sh
python -m pip install -r requirements.txt
jupyter lab work.ipynb
```

Запускайте ячейки сверху вниз, рабочая папка — `labs/lab-06/`.

## Проверка

```sh
python test_work.py
```

Тест загружает определения из `work.ipynb` и проверяет поведение функций или модели. Полное обучение и загрузка датасетов для теста не нужны.

CIFAR-10: фиксированная подвыборка 10 000 train / 2 000 validation. Официальный test не используется для подбора. Данные загружаются в `../../.lab-data/`.
