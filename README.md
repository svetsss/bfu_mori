# МОРИ: практические и домашние работы

Учебные ноутбуки и Python-код по машинному обучению.

- `coursework/` — практики, домашние задания и код MNIST.
- `practice-03/` — персептрон, сигмоида и LogLoss.

Точные копии удалены при переносе; различающиеся версии сохранены с исходными именами. Окружения Python, скачанные данные MNIST и ZIP-копии не включены.

Для запуска ноутбуков установите Jupyter и библиотеки из импортов соответствующей работы.
